## 3. 语料与数据流

### 3.1 语料生成

父工程 `i18n/scripts/sync-i18n.mjs` 读取 `i18n/{common,app}/{zh-CN,en-US,zh-TW}.json`，合并 `common` + `app` 域为扁平键集，生成本工程语料模块：

```
miniprogram/i18n/
├── zh-CN.ts     # export default { "app.name": "tpl-workspace", ... }
├── en-US.ts     # export default { "app.name": "tpl-workspace", ... }
└── zh-TW.ts     # export default { "app.name": "tpl-workspace", ... }
```

- 点号 key 原样保留（与 vue-i18n 不同，不做 `.`→`_` 转换）
- 文件头标记 `Auto-generated by i18n/scripts/sync-i18n.mjs`，禁止手动编辑
- 覆盖键域：`app.*`、`dict.*`、`ui.*`、`common.*`、`message.*`、`auth.*`、`profile.*` 等，约 210 余键

### 3.2 运行时数据流

```
app.onLaunch
   └─ getLocale() 读 storage('language')，缺省归一化系统语言
   └─ applyTabBarLocale() 重写 tabBar 文案
页面渲染 / 事件
   └─ t(key, args?) 按当前语言取词 + 插值
网络请求
   └─ utils/request.ts
        ├─ 401 → t('message.error.unauthorized')
        ├─ 失败 → translateApiMessage(R.msg)
        └─ 网络异常 → t('message.error.network')
语言切换
   └─ setLocale(lang) 写 storage + applyTabBarLocale()
        └─ 各页面 onShow 重新调用 t() 刷新
```

## 4. 核心模块设计

### 4.1 `miniprogram/utils/i18n.ts`

全部导出项：

| 导出 | 类型 | 说明 |
|------|------|------|
| `Locale` | type | `'zh-CN' \| 'en-US' \| 'zh-TW'` |
| `LOCALES` | `Locale[]` | 全部支持语言 |
| `I18nArgs` | type | `Record<string, string \| number>` |
| `getLocale()` | `() => Locale` | 读语言偏好 |
| `setLocale(lang)` | `(lang: Locale) => void` | 切换语言 |
| `t(key, args?)` | `(key: string, args?: I18nArgs) => string` | 取词 + 插值 |
| `translateApiMessage(msg, args?)` | `(msg?: string, args?: I18nArgs) => string` | 后端 key 翻译 |
| `applyTabBarLocale()` | `() => void` | 重写 tabBar 文案 |

#### 4.1.1 语料映射

```typescript
import zhCN from '../i18n/zh-CN'
import enUS from '../i18n/en-US'
import zhTW from '../i18n/zh-TW'

const MESSAGES: Record<Locale, Record<string, string>> = {
  'zh-CN': zhCN as Record<string, string>,
  'en-US': enUS as Record<string, string>,
  'zh-TW': zhTW as Record<string, string>,
}
```

#### 4.1.2 `getLocale()` 语言归一化

```typescript
function normalizeSystemLocale(lang: string): Locale {
  const l = lang.toLowerCase()
  if (l.startsWith('zh') && (l.includes('tw') || l.includes('hk') || l.includes('mo') || l.includes('hant'))) {
    return 'zh-TW'
  }
  if (l.startsWith('zh')) return 'zh-CN'
  if (l.startsWith('en')) return 'en-US'
  return 'zh-CN'
}

export function getLocale(): Locale {
  const stored = wx.getStorageSync(STORAGE_KEYS.LANGUAGE)
  if (isLocale(stored)) return stored
  let systemLang = 'zh-CN'
  try {
    systemLang = wx.getSystemInfoSync().language || 'zh-CN'
  } catch { /* getSystemInfoSync 失败使用默认 */ }
  return normalizeSystemLocale(systemLang)
}
```

#### 4.1.3 `t()` 取词 + 插值 + 兜底

```typescript
export function t(key: string, args?: I18nArgs): string {
  const current = MESSAGES[getLocale()]
  let template = current[key]
  if (typeof template !== 'string') {
    template = MESSAGES['zh-CN'][key]   // 回退事实源
  }
  if (typeof template !== 'string') {
    return key                            // 回退原 key
  }
  return interpolate(template, args)
}

function interpolate(template: string, args?: I18nArgs): string {
  if (!args) return template
  return template.replace(/\{(\w+)\}/g, (match, name: string) => {
    const value = args[name]
    return value === undefined || value === null ? match : String(value)
  })
}
```

兜底顺序：当前语言 → zh-CN → 原 key。任一步不抛异常。

#### 4.1.4 `translateApiMessage()`

```typescript
export function translateApiMessage(msg?: string, args?: I18nArgs): string {
  if (!msg) return ''
  return t(msg, args)
}
```

#### 4.1.5 `setLocale()` / `applyTabBarLocale()`

```typescript
const TAB_BAR_ITEMS: { pagePath: string; key: string }[] = [
  { pagePath: 'pages/profile/profile', key: 'profile.title' },
  { pagePath: 'pages/profile/profile', key: 'auth.profile.title' },
]

export function applyTabBarLocale(): void {
  TAB_BAR_ITEMS.forEach((item, index) => {
    try {
      wx.setTabBarItem({ index, text: t(item.key) })
    } catch { /* 无 tabBar 页面 / 未就绪时忽略 */ }
  })
}

export function setLocale(lang: Locale): void {
  wx.setStorageSync(STORAGE_KEYS.LANGUAGE, lang)
  applyTabBarLocale()
}
```

`TAB_BAR_ITEMS` 顺序与 `app.json` tabBar `list` 一致，逐项用 `wx.setTabBarItem` 重写 `text`。各页面通过 `onShow` 重新调用 `t()` 刷新自身文案。

### 4.3 `miniprogram/utils/request.ts`（后端 key 翻译）

```typescript
import { t, translateApiMessage } from './i18n'

// 401：未授权
wx.showToast({ title: t('message.error.unauthorized'), icon: 'none', duration: 2000 })

// 业务失败：R.msg（i18n key）→ 翻译
const msg = extractErrorMsg(res.data)
wx.showToast({ title: translateApiMessage(msg), icon: 'none' })

// 网络异常
wx.showToast({ title: t('message.error.network'), icon: 'none' })

function extractErrorMsg(data): string {
  if (data && typeof data === 'object') {
    const msg = (data as { msg?: unknown }).msg
    if (typeof msg === 'string' && msg) return msg
  }
  return 'message.error.serverBusy'
}
```

要点：

- 后端返回 `R.msg` 已是 i18n key，`extractErrorMsg` 提取 key，`translateApiMessage` 翻译后展示。
- 后端未返回 msg 时回退 `message.error.serverBusy`（仍是 key，翻译后显示"服务器繁忙"）。

## 7. 语言切换流程

### 7.1 默认跟随系统

```
app.onLaunch
   └─ getLocale()
        ├─ storage('language') 存在且合法 → 返回
        └─ 否则 wx.getSystemInfoSync().language → normalizeSystemLocale
             zh_TW / zh-HK / zh-MO / zh-Hant* → zh-TW
             zh* → zh-CN
             en* → en-US
             其他 → zh-CN
```

### 7.2 应用内切换

```
用户选择语言
   └─ setLocale(lang)
        ├─ wx.setStorageSync('language', lang)
        ├─ applyTabBarLocale()（wx.setTabBarItem 逐项重写）
        └─ 各页面 onShow 重新 t() 刷新
```

### 7.3 tabBar 重写时序

- `onLaunch` 时 `applyTabBarLocale()` 可能在 tabBar 就绪前执行，`wx.setTabBarItem` 抛异常被 catch 忽略。
- 两个 tab 页（profile、profile）在各自 `onShow` 再次应用，确保最终文案正确。

## 8. 关键算法

### 8.1 语言归一化矩阵

| 输入 | 输出 |
|------|------|
| `zh_CN` / `zh-Hans-CN` / `zh` | `zh-CN` |
| `zh_TW` / `zh-HK` / `zh-MO` / `zh-Hant-TW` | `zh-TW` |
| `en` / `en-US` / `en-GB` | `en-US` |
| `fr` / `ja` / 其他 | `zh-CN` |

### 8.2 占位符插值

- 模板 `"{countdown}s 后重发"` + args `{countdown: 45}` → `"45s 后重发"`
- 参数缺失或为 null/undefined → 保留原 `{name}` 占位符

### 8.3 兜底链

```
t(key) 命中当前语料 → 返回
       ↓ 未命中
       命中 zh-CN → 返回
       ↓ 未命中
       返回原 key
```

## 9. 错误处理策略

| 场景 | 处理 |
|------|------|
| `wx.getStorageSync('language')` 非合法 locale | 回退系统语言归一化 |
| `wx.getSystemInfoSync()` 抛异常 | catch 后回退 `zh-CN` |
| `wx.setTabBarItem` 抛异常（tabBar 未就绪） | catch 忽略，待 tab 页 onShow 再应用 |
| 语料缺失 key | 回退 zh-CN，再回退原 key，不抛异常 |
| 占位符参数缺失 | 保留原占位符 |
| 后端 msg 为空 | `translateApiMessage` 返回空串，`extractErrorMsg` 兜底 `message.error.serverBusy` |

## 12. 风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| tabBar 重写时机早于 tabBar 就绪 | 中 | `wx.setTabBarItem` 包裹 try/catch，tab 页 onShow 二次应用 |
| 语料生成物被误改后又被 sync 覆盖 | 低 | 文件头标记 Auto-generated，语料变更走父工程 sync 流程 |
| en-US / zh-TW 为机器翻译初稿 | 低 | 父工程待办人工校对，本端无需改动 |
| 切语言后未回到页面的旧文案残留 | 低 | 页面 onShow 统一重取 t() |
