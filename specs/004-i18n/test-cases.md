## 1. 系统语言跟随

### TC-004-001：默认跟随系统简体中文

| 项目 | 内容 |
|------|------|
| **ID** | TC-004-001 |
| **场景** | 本地无语言偏好，系统语言为简体中文时启动小程序 |
| **优先级** | P0 |
| **前置条件** | 1. 本地 storage 无 `language` 键<br>2. 系统语言为 `zh_CN` |
| **步骤** | 1. 清除本地存储<br>2. 将微信客户端系统语言设为简体中文<br>3. 启动小程序 |
| **预期结果** | 1. 登录页、tabBar 文案显示简体中文<br>2. `getLocale()` 返回 `zh-CN` |
| **来源** | US-002, FR-004-108, AC-001 |

## 4. 后端 key 翻译

### TC-004-008：后端 R.msg key 翻译

| 项目 | 内容 |
|------|------|
| **ID** | TC-004-008 |
| **场景** | 后端返回 `R.msg="message.error.loginFailed"`，前端按当前语言翻译 |
| **优先级** | P0 |
| **前置条件** | 当前语言为英文，登录失败触发后端返回该 key |
| **步骤** | 1. 输入错误密码提交登录<br>2. 后端返回 `code!=200, msg="message.error.loginFailed"` |
| **预期结果** | toast 显示英文 `Login failed`（对应 en-US 语料），而非原 key |
| **来源** | US-004, FR-004-112, AC-005 |
