## 一、系统概述

### 1.1 系统定位


### 1.2 目标用户

- 使用微信、希望通过小程序快速访问业务功能的用户

## 三、功能需求

### 3.1 用户认证（002-user-auth）

#### 3.1.1 注册

- FR-002-001：系统 MUST 支持手机号注册，用户需提供手机号、密码
- FR-002-002：系统 MUST 在注册前校验手机号唯一性
- FR-002-003：系统 MUST 支持图形验证码校验，防止机器人注册
- FR-002-004：注册成功后 MUST 自动跳转至登录页

#### 3.1.2 登录

- FR-002-005：系统 MUST 支持密码登录（手机号 + 密码 + 图形验证码）
- FR-002-006：系统 MUST 支持短信验证码登录（手机号 + 短信验证码）
- FR-002-007：系统 MUST 支持微信一键登录（调用 `wx.login` 获取 code → 后端换取 token）
- FR-002-008：登录成功后 MUST 存储 token 到本地，后续请求自动携带
- FR-002-009：Token 过期后 MUST 自动跳转登录页

#### 3.1.3 个人信息

- FR-002-010：登录用户 MUST 可查看个人资料（昵称、头像、手机号脱敏）
- FR-002-011：登录用户 MUST 可修改昵称和头像
- FR-002-013：登录用户 MUST 可修改密码（需旧密码验证）

### 3.2 个人中心（101-profile）

- FR-101-002：系统 MUST 提供快捷入口跳转至各功能模块
- FR-101-003：未登录用户 MUST 被引导至登录页

### 3.3 基础设施（001-app-shell）

- FR-001-001：小程序 MUST 在启动时初始化本地存储
- FR-001-002：系统 MUST 提供可复用的自定义导航栏组件
- FR-001-003：系统 MUST 提供统一的时间格式化工具函数
- FR-001-004：系统 MUST 支持 Skyline 渲染引擎和 glass-easel 组件框架

## 四、非功能性需求

### 4.1 性能

- NFR-001：页面首屏渲染时间 SHOULD 在 2 秒以内
- NFR-002：API 请求 SHOULD 在 3 秒内返回结果
- NFR-003：小程序包体积 SHOULD 控制在 2MB 以内（主包）

### 4.2 用户体验

- NFR-004：所有用户操作 SHOULD 有即时反馈（按钮状态变化、加载动画、toast 提示）
- NFR-005：网络异常时 SHOULD 显示友好的错误提示
- NFR-006：表单校验错误 SHOULD 实时提示

### 4.3 兼容性

- NFR-007：系统 MUST 兼容微信基础库 ≥ 3.0.0
- NFR-008：系统 MUST 兼容 iOS 和 Android 客户端

### 4.4 安全性

- NFR-009：所有 API 请求 MUST 使用 HTTPS
- NFR-010：用户密码 MUST 加密传输（AES+RSA，与 tpl-app-api 一致）
- NFR-011：本地存储的 Token SHOULD 在退出登录时清除

## 五、假设与约束

### 5.1 假设

- **后端就绪**：tpl-app-api 已部署并提供 REST API（参考 `../docs/` 中的 API 设计）
- **微信配置就绪**：微信开放平台已配置实际 AppID（`project.config.json` 中为占位符 `wxChangeMe`，需替换为真实值）
- **用户设备**：用户使用支持 Skyline 渲染引擎的微信客户端（基础库 ≥ 3.0.0）

### 5.2 约束

- **平台约束**：遵守微信小程序平台规范和审核要求
- **架构约束**：必须使用 TypeScript + Skyline + glass-easel
- **依赖约束**：最小化外部依赖，优先使用微信原生能力
- **命名约束**：模块编号遵循项目宪法（001-099 基础设施，100-199 功能模块）

## 六、验收标准

### 6.1 用户认证验收标准

| 场景 | 验收条件 |
|------|---------|
| 密码登录 | 用户输入已注册手机号和正确密码 → 登录成功 → 进入个人中心 |
| 短信登录 | 用户输入手机号 → 获取验证码 → 输入正确验证码 → 登录成功 |
| 微信登录 | 用户点击微信登录 → 授权 → 登录成功 → 进入个人中心 |
| 登录失败 | 用户输入错误密码 → 显示"密码错误"提示 |
| Token 过期 | 请求返回 401 → 自动跳转登录页 |

### 6.2 个人中心验收标准

| 场景 | 验收条件 |
|------|---------|
| 未登录访问 | 未登录用户进入个人中心 → 跳转登录页 |
